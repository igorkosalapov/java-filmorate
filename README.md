# \# Filmorate

# 

# Filmorate — это сервис, позволяющий пользователям оценивать фильмы, ставить лайки, добавлять их в базу, просматривать популярные фильмы и дружить с другими пользователями.

# \## Пояснение к схеме

# 

# Система состоит из следующих основных сущностей:

# 

# \- \*\*users\*\* — пользователи

# \- \*\*films\*\* — фильмы

# \- \*\*film\_likes\*\* — лайки фильмов пользователями

# \- \*\*friendships\*\* — дружба между пользователями

# \- \*\*genres / film\_genres\*\* — жанры фильмов и связь многие-ко-многим

# \- \*\*mpa\_ratings\*\* — рейтинги MPA
